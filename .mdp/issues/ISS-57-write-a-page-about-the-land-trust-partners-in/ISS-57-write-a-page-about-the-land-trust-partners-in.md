## Requirement

Ben is joining the Haliburton Highlands Land Trust Partners in Conservation
programme and expects to write a page about it once that is settled. The
conversation with the organiser is already open and is his to run.

<https://www.haliburtonlandtrust.ca/partners-in-conservation-program/>

The prompt for it was My Haliburton Highlands (ISS-56), whose criteria give
priority to properties showing a commitment to sustainability. That is a
tiebreaker in their process rather than a requirement, so this does not gate
the directory application and should not be allowed to delay it.

## No longer blocked

This was parked because what the page could say depended on what PIC turned
into. Ben confirmed membership on 2026-09-15, so it is settled and the page can
be written -- subject to the wording check below.

## What the programme is

Free, and non-binding -- a participant can end it at any time, with no loss of
property rights and no land-use restriction. What it provides is stewardship
support: site visits from their staff, workshops on things like invasive plant
management and trail building, and help planning and funding work on the land.

It also includes help applying to Ontario's Managed Forest Tax Incentive
Programme, which they describe as up to 75% off the eligible area. On 23
wooded acres that is worth asking about whatever happens with the page. How
the commercial rental use interacts with the classification is a question for
them and not an assumption to make here.

## The acreage question, answered by the outcome

Inside the Highlands Corridor the programme is open at any acreage. Outside it
they were prioritising properties over 50 acres, and Highland Hideaway is 23,
so a waiting list looked like the likely outcome.

It was not: membership was granted. Whether that is because the property sits
inside the Corridor is still unknown, and now matters only for what the page
can say about the land around it. Ask, but do not wait on it.

## There is no badge to display

Participation is private. The programme publishes no list of participant names
or addresses, and the only public exposure is an opt-in to appear on coverage
maps. So there is no logo, no certification and no listing to point at.

That means the page cannot be about holding a credential. It has to describe
what is actually done on the land, which is a harder page to write and a better
one. The Corduroy post's constraint applies unchanged: no logo, no use of
"partner" or "official" in a way that implies an endorsement, and nothing
copied from their site.

Ask the organiser what wording they are comfortable with before publishing.
They are a small organisation and the cost of asking is one email.

## Acceptance criteria

A page that describes the stewardship of the property truthfully, that a reader
who has never heard of the Land Trust can follow, and that the Land Trust
itself would not object to. If PIC ends in a waiting list rather than
participation, the page says that or is not written.
